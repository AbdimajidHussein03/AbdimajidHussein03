## Featured Projects

### Aegis Platform | Azure Kubernetes & Platform Engineering

Designed and built a **production-style Kubernetes application platform on Microsoft Azure**, bringing together Infrastructure as Code, multi-service container orchestration, CI/CD, GitOps, observability and workload resilience.

The platform hosts **Hi.Events**, a containerised event management application consisting of a frontend, backend API, PostgreSQL, Redis, background workers and scheduled jobs.

- Provisioned **Azure infrastructure using modular Terraform**, including AKS, Azure Container Registry, virtual networking, NAT Gateway, network security groups and managed identity
- Deployed and managed **multiple interconnected container workloads** using Kubernetes Deployments, Services, StatefulSets, persistent storage and Helm
- Implemented **GitHub Actions CI workflows** for frontend and backend builds and security checks, alongside **Argo CD** for GitOps-based deployment management
- Built an observability stack using **Prometheus, Grafana and Alertmanager** to inspect cluster health, workload resource consumption and application performance
- Configured **readiness and liveness probes**, CPU and memory requests and limits, and Horizontal Pod Autoscaling
- Validated Kubernetes self-healing with a frontend Pod replacement becoming Ready in approximately **16 seconds**
- Conducted controlled load testing, demonstrating **automatic scaling from 1 to 2 replicas and back to 1** as CPU utilisation changed

**`Azure` · `AKS` · `Terraform` · `Kubernetes` · `Docker` · `Helm` · `GitHub Actions` · `Argo CD` · `Prometheus` · `Grafana` · `HPA`**
